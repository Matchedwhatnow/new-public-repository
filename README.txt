# Matched: What Now? - App V2

This is a complete installable web app (PWA) built from the Original Edition playbook.

FILES
- index.html - app screen
- style.css - design
- app.js - messages and app features
- manifest.json - installable-app settings
- README.txt - these instructions

WHAT IT DOES
- Message categories
- Search
- One-tap copy
- Save favourites on the device
- Random message picker
- 20-Second Message Builder
- Mobile-first layout

FREE WAY TO PUBLISH
1. Create a free GitHub account.
2. Create a new public repository (for example: matched-what-now-app).
3. Upload index.html, style.css, app.js and manifest.json.
4. Open repository Settings > Pages.
5. Under Build and deployment, choose Deploy from a branch.
6. Select main / root and Save.
7. GitHub will give you a public web address.
8. Open that address on your phone.
9. In Chrome/Android use Add to Home screen / Install app.

IMPORTANT
This package is a PWA, so it can feel like an app and be installed from a browser without paying app-store fees.
For Google Play / Apple App Store distribution later, this web app can be wrapped in a native shell (for example Capacitor) and store-specific icons, signing, privacy details and screenshots can be added.

CONTENT NOTE
The app keeps the playbook's principle: prompts are inspiration, not pressure. Respect boundaries and lack of interest.
